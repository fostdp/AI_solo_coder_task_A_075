# 智慧城市地下综合管廊燃气泄漏激光监测与联动处置系统 - 产品需求文档

## 1. 产品概述

本系统面向城市地下综合管廊燃气舱的安全监测场景，实现对30公里管廊内300台激光甲烷检测器、50台氧气/温湿度传感器的实时数据采集、可视化展示、泄漏源智能定位和应急联动处置。
- 目标用户：管廊运维人员、安全管理员、应急指挥人员
- 核心价值：将燃气泄漏从被动发现升级为主动预警+智能定位+自动处置，将响应时间从分钟级缩短至秒级

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运维人员 | 管理员分配账号 | 查看实时监测数据、告警信息、传感器状态 |
| 安全管理员 | 管理员分配账号 | 告警处置、应急联动操作、系统配置 |
| 应急指挥人员 | 管理员分配账号 | 泄漏源定位结果查看、疏散指令下达、全局态势感知 |

### 2.2 功能模块

1. **实时监测大屏**：管廊走向地图、燃气浓度热力图、检测器状态标注、实时数据流
2. **检测器详情面板**：近1小时浓度趋势图、传感器健康状态、设备信息
3. **泄漏源定位模块**：多点浓度梯度分析、管廊风速风向计算、粒子群优化/贝叶斯推断、泄漏扩散范围可视化
4. **告警管理中心**：三级告警规则配置、告警列表、告警处置流程
5. **应急联动控制**：阀门远程控制、排风机启停、疏散通知推送、MQTT指令模拟

## 3. 核心流程

### 3.1 实时监测流程
检测器每秒上报甲烷浓度 → 后端写入InfluxDB → 前端通过WebSocket实时接收 → 热力图和检测器颜色实时更新

### 3.2 告警触发流程
浓度数据入库 → 后端规则引擎判断是否超阈值 → 10%LEL一级预警/20%LEL二级报警/50%LEL三级紧急关断 → MQTT+短信双通道推送告警

### 3.3 泄漏源定位流程
多点检测器浓度数据采集 → 浓度梯度计算 → 结合管廊风速风向 → 粒子群优化或贝叶斯推断反演 → 输出泄漏源位置和泄漏速率 → 地图上标注扩散范围

### 3.4 应急联动流程
二级报警触发 → 自动关闭对应防火分区阀门(MQTT) → 启动排风机(MQTT) → 推送疏散通知 → 前端实时显示联动状态

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝黑(#0a1628)背景 + 科技蓝(#00d4ff)主色 + 红橙(#ff4444/#ff8800)告警色
- **辅助色**：绿(#00ff88)正常状态、黄(#ffdd00)预警、紫(#b44dff)数据可视化
- **设计风格**：工业监控SCADA风格 + 现代数据可视化，深色科技风大屏
- **字体**：数据展示用等宽字体(JetBrains Mono)，标签用思源黑体
- **布局**：全屏地图为主，左侧传感器列表侧栏，右侧告警面板，底部状态栏
- **图标**：圆形状态指示灯 + 线性图标(lucide-react)

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 实时监测大屏 | 管廊地图区 | 深色底图，管廊线路用青色线条，热力图半透明叠加，检测器圆点4-8px |
| 实时监测大屏 | 检测器弹窗 | 暗色卡片，折线图(黑底青线)，健康状态指示灯，设备参数表格 |
| 实时监测大屏 | 泄漏源标注 | 红色脉冲圆圈(动画)，扩散范围半透明红色填充 |
| 实时监测大屏 | 左侧传感器列表 | 可滚动列表，每行显示ID+浓度+状态灯 |
| 实时监测大屏 | 右侧告警面板 | 告警卡片列表，颜色编码(黄/橙/红)，闪烁动画 |
| 告警管理 | 告警列表 | 表格布局，筛选栏，分页，级别标签 |
| 应急联动 | 控制面板 | 设备卡片，开关按钮(绿开/红关)，状态指示 |

### 4.3 响应式设计

- 桌面优先（1920x1080大屏展示）
- 最小支持1366x768分辨率
- 地图区域自适应填满可用空间

### 4.4 动画效果

- 检测器颜色变化：平滑渐变过渡
- 泄漏扩散范围：脉冲扩展动画
- 告警闪烁：关键告警脉冲闪烁
- 热力图：流动渐变效果
- 弹窗：淡入淡出 + 轻微缩放
